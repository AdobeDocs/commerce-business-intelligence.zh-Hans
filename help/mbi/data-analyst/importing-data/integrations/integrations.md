# 使用集成连接外部数据

集成就是数据源。 集成是可以连接到Data Warehouse的应用程序与数据库。

此部分介绍可用于将各种外部数据源连接到[!DNL Commerce Intelligence]的可用集成。

要删除连接或集成，请[联系支持人员](https://experienceleague.adobe.com/zh-hans/docs/commerce-knowledge-base/kb/troubleshooting/miscellaneous/mbi-service-policies)并包含要删除的连接或集成的名称。
